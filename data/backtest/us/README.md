# 美股日线回测数据集

面向策略回测的美股全市场日线数据，**包含已退市股票**，可直接用于无幸存者偏差
（survivorship-bias-free）的历史回测。

- 区间：**2006-01-03 ~ 2024-12-31（19 个自然年）**；2025 年数据待补
- 复权：**前复权，总回报口径**——OHLC 经拆股/合股/送股与现金分红调整，持有
  期间的分红已含在价格连续性中
- 频率：日线
- 规模：普通股 11,970 只（含区间内退市的股票）、2394 万行

## 如何消除幸存者偏差

股票范围为 19 年间**全部上市过的普通股**，包括在此期间退市的标的——它们退市前的
完整行情都在数据集中，没有做任何"当前在市"过滤。构造任意历史时点的可交易股票池
时，以**当日是否存在行情记录**为准；退市股在退市次日后自然不再出现。

## 文件说明

| 文件 | 内容 |
|---|---|
| `daily_stocks.parquet` | 全部普通股日线（含退市），ZSTD 压缩，按 `code, date` 排序 |
| `daily_indices.parquet` | 4 只基准指数日线（2006–2025），列结构与个股完全一致 |
| `securities.csv` | 全部历史标的的对照/生命周期表（含未纳入的非普通股，`included` 标志区分） |
| `delisting_returns.csv` | 退市期间收益表（成品 `pctChg` 已在末日并入，本表完整另存） |

`securities.csv` 字段：`code, permno, ticker, name, exchcd, shrcd, first_date,
last_date, active, included, dlstcd`。

`delisting_returns.csv` 字段：`code, date, dlret_pct`（每证券一行，退市期间
收益率 %）。

## 字段

| 字段 | 类型 | 含义 |
|---|---|---|
| `date` | TIMESTAMP | 交易日 |
| `code` | VARCHAR | 证券代码，格式 `us.<permno>` |
| `open` / `high` / `low` / `close` | DOUBLE | 前复权开高低收（美元，总回报口径） |
| `volume` | BIGINT | 成交量（股）；零成交但有有效报价的日子保留记录、成交量为 0 |
| `amount` | DOUBLE | 成交额（美元，`\|prc\| × volume`） |
| `turn` | DOUBLE | 换手率（%，成交量 / 流通股数） |
| `pctChg` | DOUBLE | 日涨跌幅（%，总回报口径） |

除退市末日外，`pctChg` 与前复权 `close` 的逐日比值恒等；退市末日因收盘价无法
包含退市期间收益而存在缺口，退市收益见 `delisting_returns.csv`。官方值缺失时用
相邻保留日的前复权收盘比补算（超 ±400% 不可信则留空），首日无官方收益则留空。

## 基准指数

| 代码 | 名称 |
|---|---|
| `us.DJI` | 道琼斯工业平均指数 |
| `us.SPX` | 标普 500 指数 |
| `us.IXIC` | 纳斯达克综合指数 |
| `us.RUT` | 罗素 2000 指数 |

指数为点位序列（价格指数口径），无成交量/成交额/换手率：`volume=0`、
`amount/turn=NULL`；`pctChg` 由相邻收盘点位比计算。数据在 `daily_indices.parquet`
中，区间 2006–2025。

## 代码规则

代码使用 **PERMNO**（证券永久标识），format 为 `us.<permno>`（如 `us.14593`）。
PERMNO 不随股票改名、代码回收而变化；行情软件中常见的 ticker 会被回收复用，
不能作为历史数据的唯一标识。代码与名称的对照见 `securities.csv`。

交易所代码 `exchcd`：1=NYSE，2=NYSE MKT/AMEX，3=Nasdaq，4=NYSE Arca，5=其他。

## 已知口径

- 无任何有效信息的日子（无报价、无成交）不保留记录；**零成交但有有效买卖
  报价的日子保留**（`volume=0`，`close` 为当日报价均值），它们是相邻交易日
  收益的计价基准；
- 同一交易日有多个公司行为时，各价格因子按 facpr 相加合并，事件比例
  `1/(1+Σfacpr)`；公司行为落在无行情占位日时，调整自动并入下一有效交易日；
- 现金分红没有独立金额列：分红效应仅在 facpr 显式非空的"分布事件日"上，由
  官方日收益恒等式 `(1+RET)/[(原始价比)(1+Σfacpr)]` 提取分红财富因子（非
  事件日不提取——RET 仅 6 位小数，残差噪声过大）；
- **开盘价缺失（源记 0，多为盘中才出现首笔交易）时保留 NULL，不做填充**；
  共约 51 万行（其中约 34 万为零成交日报价行、约 17 万为有成交但无开盘的
  盘中恢复交易日）。
